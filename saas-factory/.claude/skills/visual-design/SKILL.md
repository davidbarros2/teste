# Visual design

Last reviewed: 2026-10.

## Rules
1. Start from a design system: spacing scale (4/8 px), type scale, color
   tokens, components. Use an established UI library before custom work.
2. Hierarchy through size, weight and color, not only size.
3. Typography: 1-2 families, body 16 px+, line length 45-75 characters,
   line height ~1.5 for body.
4. Color: one primary, neutrals, semantic colors (success, warning, danger);
   all pairs meet WCAG contrast. Define light and dark tokens if supported.
5. Generous whitespace; align to a grid; consistent radii and shadows.
6. Icons from one set; meaning never by icon alone.
7. Brand: simple logo that works at 16 px and in one color; consistent use.
8. Real content in designs, never lorem ipsum at review time.

## Audit checklist
- [ ] Tokens defined and used consistently
- [ ] Contrast checked for every text/background pair
- [ ] Clear visual hierarchy on each screen (one focal point)
- [ ] Responsive at 360 px, 768 px, 1280 px
