# Onboarding and activation

Last reviewed: 2026-10.

## Rules
1. Define the activation event: the action that predicts retention
   (e.g. "first appointment booked"). Measure time to it.
2. Remove steps before the first value; defer profile, settings, invites.
3. Use templates, sample data or imports so users never face a blank screen.
4. Empty states teach: what goes here, why it matters, one button to start.
5. Checklists only for the few steps that lead to activation.
6. Trial emails are behavior-based: nudge the next step the user has not done.
7. Offer human help early (a short call) in B2B; learn from every call.

## Audit checklist
- [ ] Activation event defined and tracked
- [ ] Steps from sign-up to activation counted and minimized
- [ ] Every empty state designed
- [ ] Trial email sequence tied to user behavior
