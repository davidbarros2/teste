# SEO

Last reviewed: 2026-10.

## Rules
1. People-first content: answers a real question better than what ranks today;
   shows first-hand experience.
2. One primary intent per page. Title ≤ 60 chars, meta description ≤ 155,
   one H1, logical heading order.
3. Descriptive URLs; internal links with meaningful anchor text.
4. Technical: HTTPS, sitemap.xml, robots.txt, canonical tags, no indexable
   duplicates, `hreflang` for multiple languages.
5. Performance: Core Web Vitals in "good" (skill `web-performance`).
6. Structured data where it fits (Organization, SoftwareApplication, FAQ, Article).
7. Images: descriptive alt text, modern formats, explicit dimensions.
8. No keyword stuffing, doorway pages, scaled low-value AI content or bought links.

## Audit checklist
- [ ] Clear intent and unique value per page
- [ ] Title, description, H1, canonical present and unique
- [ ] Indexing setup verified in Search Console
- [ ] Structured data valid
- [ ] No spam-policy risks
