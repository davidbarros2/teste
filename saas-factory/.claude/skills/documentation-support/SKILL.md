# Documentation and support

Last reviewed: 2026-10.

## Docs structure (Diátaxis)
- Tutorials (learning): getting started to first value.
- How-to guides (tasks): one goal per page.
- Reference (facts): settings, limits, API.
- Explanation (understanding): concepts, why things work this way.

## Rules
1. Write from real support questions; every repeated question becomes a doc.
2. Task titles start with a verb ("Export your data").
3. Screenshots current; steps numbered; one action per step.
4. Mandatory pages: getting started, billing and cancellation, data export
   and deletion, security and privacy summary, contact.
5. Support: one channel to start, a stated response time, saved replies
   written with `human-writing`, a log of themes for the weekly review.

## Audit checklist
- [ ] Mandatory pages exist and are current
- [ ] Top 10 support questions have docs
- [ ] Response time promise met in the last month
