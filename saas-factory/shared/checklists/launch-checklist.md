# Launch checklist

## Legal and tax
- [ ] Terms, privacy notice, cookie handling, DPA, subprocessors published
- [ ] Company identification in footer as required
- [ ] VAT/OSS and invoicing tested with a real payment
- [ ] B2C (if applicable): withdrawal info, complaints book (PT), ADR info

## Product
- [ ] Core flows tested end to end in production
- [ ] Tenant isolation tests green
- [ ] Accessibility AA on sign-up, core job, billing
- [ ] Empty, error and loading states reviewed

## Operations
- [ ] Error tracking and uptime alerts reach the founder's phone
- [ ] Backup restore tested this month
- [ ] Incident runbook and support inbox ready

## Marketing
- [ ] Landing page audited (copy, SEO, Core Web Vitals, a11y)
- [ ] Analytics with consent handled; conversion events defined
- [ ] SPF, DKIM, DMARC pass for the sending domain
- [ ] Help center live: getting started, FAQ, billing, data deletion
