# Distribution 03: Publish

## Inputs
| Source | File | Scope |
|---|---|---|
| Draft | `../02_draft/output/<piece>.md` | Full |
| Skill | `content-distribution` | "Channel norms" |
| Calendar | `output/calendar.md` | Full |

## Process
1. Adapt the piece per channel (length, format, norms; disclose affiliation).
2. Add it to the calendar with date, channel and link.
3. ⏸ Founder publishes. Later, record results in `output/results.md`.

## Outputs
`output/calendar.md`, `output/results.md`, `output/<piece>-<channel>.md`.

## Gate
- [ ] Channel rules respected; UTM or equivalent tracking set
