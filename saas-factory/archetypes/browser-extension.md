# Archetype: Browser extension

## Technical
- Minimal permissions (store reviews reject broad ones); Manifest V3.
- Backend for accounts and billing; extension never holds secrets.

## Legal
- Store policies (Chrome Web Store, Firefox add-ons) on data use and disclosure.
- Privacy policy must explain exactly what page data is read.

## Pricing
- Freemium with paid features is the norm; license check via backend.

## Distribution
- Store listing optimization, reviews, niche communities, content.
