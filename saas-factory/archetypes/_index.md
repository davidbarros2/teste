# Archetypes

A product declares one or more archetypes in `META.md`. Each adds technical,
legal, pricing and distribution specifics on top of the default pipeline.

| File | Use when |
|---|---|
| b2b-webapp.md | Web app sold to businesses or professionals (default) |
| b2c-webapp.md | Web app sold to consumers |
| developer-api.md | API or SDK sold to developers |
| browser-extension.md | Chrome/Firefox/Edge extension |
| marketplace-plugin.md | App inside another platform (Shopify, Slack, Notion...) |
| ai-powered.md | Core value depends on an AI model (combine with another) |
| regulated-sector.md | Health, finance, education of minors, legal (combine) |
