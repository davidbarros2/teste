# Archetype: Developer API

- OpenAPI contract first; versioning policy; idempotency keys for writes.
- API keys per environment, scoped, rotatable; rate limits; usage metering.
- Docs are the product: quickstart under 5 minutes, code samples, status page.

- Acceptable use policy; SLA terms if promised; data processing as processor.

## Pricing
- Usage-based tiers with a free allowance; clear overage rules.

## Distribution
- Docs SEO, GitHub, developer communities, integrations, example projects.
