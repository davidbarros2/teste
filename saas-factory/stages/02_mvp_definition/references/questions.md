# 02 MVP definition questions

1. Which single job must the MVP do perfectly? (propose from synthesis)
2. Which features from interviews go to "later"? (propose list)
3. Plans: one plan, good/better, or good/better/best?
4. Trial: no-card trial, card-required trial, or freemium?
5. Billing: monthly only, monthly + annual, annual only?
6. Platforms: web desktop, web mobile-friendly, native mobile later?
7. Integrations needed on day one (calendar, email, accounting...)?
8. Any data the product must not store (to reduce GDPR exposure)?
