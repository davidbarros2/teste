# 06 Beta

**Goal:** real users reach the core value; fix what blocks them.

## Inputs
| Source | File | Scope |
|---|---|---|
| Validation | `{P}/stages/01_validation/output/synthesis.md` | Contacts, signals |
| PRD | `{P}/stages/02_mvp_definition/output/PRD.md` | Success metrics |
| Skills | `customer-research`, `onboarding-activation`, `product-analytics`, `documentation-support` | Full |
| Founder material | `output/feedback/*.md` | All (after checkpoint) |
| Questions | `references/questions.md` | Full |

## Process
1. `beta-plan.md`: who (5-20 users), invitation message, what to observe,
   activation metric, feedback channel, duration.
2. Draft invitations and the welcome email (human-writing audited).
3. ⏸ Checkpoint: founder invites users, holds calls; notes to `output/feedback/`.
4. `feedback.md`: issues by severity and frequency, quotes, activation data.
5. `fix-list.md`: must-fix before launch vs later; add must-fix items to
   `05_build/output/tasks.md` and run the build loop.
6. Collect testimonials with explicit permission to publish.

## Outputs
`beta-plan.md`, `feedback.md`, `fix-list.md`, `testimonials.md`, `GATE.md`.

## Gate
- [ ] ≥ 60% of beta users reached the activation event (or reasons known)
- [ ] All must-fix items closed
- [ ] At least one real payment processed end to end
