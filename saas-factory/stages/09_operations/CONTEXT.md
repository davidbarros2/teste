# 09 Operations

**Goal:** a weekly rhythm that keeps the product healthy and growing.

## Inputs
| Source | File | Scope |
|---|---|---|
| Status | `{P}/STATUS.md`, `{P}/META.md` | Full |
| Last review | `output/weeks/<latest>.md` | Full |
| Roadmap | `output/roadmap.md` | Full |
| Founder data | metrics, support notes, incidents the founder pastes or links | This week |
| Skills | `product-analytics`, `reliability-operations`, `security`, `documentation-support` | As needed |
| Routine | `references/weekly-routine.md` | Full |

## Process
Weekly review: follow `references/weekly-routine.md`, write
`output/weeks/YYYY-Www.md` from `shared/templates/weekly-review.md`.
New feature: create `output/features/<name>/` and run mini-versions of the
02 (PRD), 03 (design/ADR) and 05 (tasks) contracts inside it.
Quarterly: re-check legal-framework dates, skills reviews, pricing, and the
grow / maintain / sell / sunset decision.

## Outputs
`weeks/`, `roadmap.md`, `features/`, `incidents/` in `output/`.

## Gate (per weekly review)
- [ ] Metrics recorded vs last week
- [ ] Security updates applied or scheduled
- [ ] Next week's top 3 priorities agreed
