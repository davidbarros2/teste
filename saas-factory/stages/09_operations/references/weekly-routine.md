# Weekly routine

1. Metrics: MRR, new/churned customers, trial conversion, activation, traffic.
   Compare with last week; explain changes, do not just list them.
2. Support: themes, response times, docs to add or fix.
3. Reliability: incidents, error trends, uptime, backup status.
4. Security: dependency updates, advisories, access review (monthly).
5. Churn: reasons from cancellations; one action to reduce it.
6. Roadmap: re-rank by paying-customer value; pick next week's top 3.
7. Distribution: what content shipped, what performed, next pieces.
8. Time spent vs plan (founder capacity in founder.md).
